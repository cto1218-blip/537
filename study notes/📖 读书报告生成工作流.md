# 📖 读书报告生成工作流模板

> 标准化流程，确保每次生成都包含 HTML + Markdown 两种格式

---

## 🎯 标准流程（三阶段工作流）

### 📋 阶段 1：初稿审阅（HTML Only）

#### Step 1：解析书籍内容
```bash
# 如果是 epub 格式
unzip book.epub -d /tmp/book_temp/
# 提取章节结构和内容
```

#### Step 2：生成 HTML 初稿
- 章节摘要
- 金句提炼（每章3个）
- 核心观点节录
- "思考篇章"（连接2026现实）
- 绿色主题（或其他主题色）
- 响应式设计 + 卡片式布局

**保存位置：** `~/.openclaw/workspace/study notes/《书名》阅读指南_绿色版.html`

**在浏览器中打开查看** → 等待用户反馈

#### Step 3：迭代修改（如需要）
- 根据用户反馈调整内容/排版
- 重新生成 HTML
- 重复直到用户满意

---

### ✅ 阶段 2：定稿后批量生成（MD + PDF）

**触发条件：** 用户确认"定稿了"或"可以了"

#### Step 4：生成 Markdown 版本
将 HTML 转换为 Markdown（保留结构和格式）

**保存位置：** `~/.openclaw/workspace/study notes/《书名》阅读指南.md`

#### Step 5：生成 PDF 版本
使用 Playwright 将 HTML 转换为 PDF：
- 保持原有样式（绿色主题）
- A4 纸张格式
- 适合打印和分享

**保存位置：** `~/.openclaw/workspace/study notes/《书名》阅读指南.pdf`

#### Step 6：质量检查
- [ ] HTML 版本在浏览器中正常显示
- [ ] Markdown 版本在 Obsidian 中正常显示
- [ ] PDF 版本可以正常打开和打印
- [ ] 三个文件内容一致

---

### 📝 阶段 3：更新索引

#### Step 7：更新 README.md
在 `study notes/README.md` 中添加新条目：
```markdown
### [[《新书名》阅读指南]]
- **作者：** XXX
- **标签：** #标签1 #标签2
- **格式：** [Markdown版](XXX.md) | [HTML版](XXX.html) | [PDF版](XXX.pdf)
- **核心概念：** ...
```

#### Step 8：刷新 Obsidian
`Cmd + R` 刷新文件索引

## 📂 文件命名规范

### Markdown 文件
```
《书名》阅读指南.md
《书名》NotebookLM风格解析.md
```

### HTML 文件
```
《书名》阅读指南_绿色版.html
《书名》阅读指南_蓝色版.html
```

### PDF 文件
```
《书名》阅读指南.pdf
《书名》NotebookLM风格解析.pdf
```

**命名原则：**
- HTML 版本标注主题色（_绿色版、_蓝色版等）
- MD 和 PDF 版本使用基础文件名（无后缀）
- 保持简洁，避免特殊字符

## 🛠️ 常用工具命令

### 生成 PDF（Playwright）
```bash
python3 << 'EOF'
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    context = browser.new_context(
        viewport={"width": 1400, "height": 900},
        is_mobile=False
    )
    page = context.new_page()
    page.goto(f'file:///path/to/file.html')
    page.pdf(
        path='output.pdf',
        format='A4',
        print_background=True,
        scale=0.8
    )
    browser.close()
EOF
```

### 批量转换 HTML → Markdown
```bash
pip3 install beautifulsoup4
python3 /path/to/html2md_converter.py
```

### 生成知识库总索引
```bash
python3 generate_index.py --output "📚 我的知识库总索引.html"
```

### 刷新 Obsidian 索引
```
Cmd + R (在 Obsidian 中)
```

### 快速预览 PDF
```bash
open file.pdf
```

    </div>
