## 💡 使用说明

### Obsidian 用户
- 点击 `[[...]]` 双向链接直接跳转
- 使用 `Cmd + O` 全局搜索
- 使用 `Cmd + G` 查看知识图谱

### HTML 版本用途
- 🖨️ 打印成纸质版
- 📤 分享给朋友（直接发 HTML 文件）
- 🌐 在浏览器里阅读（更好的视觉体验）
- ✅ **初稿审阅**（快速预览，反复迭代）

### Markdown 版本用途
- ✏️ 在 Obsidian 里编辑和标注
- 🔗 创建双向链接
- 🏷️ 添加标签和元数据
- ✅ **定稿后生成**（用于知识库管理）

### PDF 版本用途
- 📄 正式存档（不易被修改）
- 🎁 分享给长辈/领导（更正式）
- 📧 邮件附件（通用格式）
- 📱 手机/平板阅读（保持排版）
- ✅ **定稿后生成**（最终版本）

## 🎨 文件命名规范

以后所有读书报告将遵循：

### 三阶段生成规范

**阶段 1：HTML 初稿**
- 文件名：`《书名》阅读指南_绿色版.html`（或其他主题色）
- 用途：浏览器查看、反复修改、确认定稿

**阶段 2：定稿后批量生成**
- Markdown：`《书名》阅读指南.md`（Obsidian）
- PDF：`《书名》阅读指南.pdf`（存档/分享）

**存放位置：** 统一存放在 `study notes/` 文件夹

### 版本标注规则
- HTML 文件标注主题色（_绿色版、_蓝色版等）
- MD 和 PDF 使用基础文件名（无颜色后缀）
- 避免特殊字符和空格（用中文书名号）
