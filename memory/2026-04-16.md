## 关键教训（绝对不能重复的错误）

### 🔴 1. 时间格式（非常重要！）
- ❌ **错误**：ISO 8601 格式 `"2026-04-16T13:00:00.000Z"`
- ✅ **正确**：中文格式 `"2026年4月16日 13:00"`
- **原因**：HTML 仪表板显示的是中文日期，ISO 格式会导致时间显示错误

### 🔴 2. 数据真实性验证
- ❌ **错误**：使用历史数据（如 4月14日的金价）
- ✅ **正确**：搜索时必须包含 "today" 或当前日期
- **验证方法**：金价 >$4,000 或 <$1,500 视为异常，必须重新搜索

### 🔴 3. Git 操作安全
- ❌ **错误**：`git add -A`（会包含嵌套仓库）
- ✅ **正确**：只 add 必要文件 `git add middle-east-tracker-zh-TW.html update-middle-east.py`
- **预防**：定期检查 workspace 是否有嵌套 git 仓库

### 🔴 4. Cron 任务设计原则
- **指令长度**：< 150 字符为最佳
- **步骤数量**：≤ 5 步
- **语言风格**：命令式，不解释原因
- **Timeout 设置**：180秒（既能完成任务，又能强制快速决策）

### 🔴 5. 新闻内容要求
- ❌ **错误**：只有标题（如"加沙停火6个月"）
- ✅ **正确**：标题 + 完整描述（150-250字，包含具体数据和背景）
- **示例**：
  ```json
  {
    "title": "加沙停火6个月，进展有限但冲突基本停止",
  ```
