## PDF布局问题修复

### 问题
生成的PDF仍然是单列移动端布局，不是桌面版的两列布局。

### 原因
HTML文件包含响应式CSS（@media query），Playwright默认触发了移动端布局。

### 解决方案
强制使用桌面版布局：
- 创建browser context时设置 `is_mobile=False`
- 明确设置 `has_touch=False`
- 使用桌面版User Agent
- 视口宽度：1400px（确保触发桌面版CSS）
- 缩放比例：0.75（适配A4纸张）

### 技术细节
```python
context = await browser.new_context(
    viewport={"width": 1400, "height": 900},
    is_mobile=False,
    has_touch=False,
    user_agent="Mozilla/5.0 (Macintosh; ...)"
)
```

### 最终效果
- PDF显示为两列桌面版布局
- 表格完整显示不压缩
- 文件大小：1.53 MB
